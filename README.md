# 五岔路口交通灯相位优化设计 (Traffic-Light-Optimization)

## 一、问题分析
本题是一个典型的五岔路口（包含单向出口C和E），总共有13条合法的可通行路线。由于路口空间有限，部分路线存在交叉、合流或分流冲突，不能同时通行（如 E->B 和 A->D）；而部分路线没有交叉，可以同时通行（如 A->B 和 E->C）。
本项目按照课程图片的分组规则，对通行路线进行相位划分，设计一套安全可行的交通灯调度方案。

## 二、算法设计思路 (图论着色模型)
本设计将交通灯相位调度问题抽象为图论中的“图着色问题”：
1. 节点：将 13 条可通行路线看作图的13个节点。
2. 边（冲突）：如果两条路线在路口会发生冲突，则在它们之间连一条边。
3. 着色（相位）：给节点分配颜色，同一种颜色代表同一个绿灯相位（可以同时通行）。
4. 目标：使用最少的颜色数（最少相位）完成对所有节点的着色，保证相邻节点颜色不同。

> 补充说明：BA、DC、ED三条右转线路为孤立顶点，无冲突，不受信号灯控制；EA线路除相位1外，其余相位均可通行。按照课程图片分组，最终划分4个相位循环放行。

## 三、程序实现
使用 C 语言编写了贪心着色算法 (Greedy Coloring)：
- 建立了13×13的冲突邻接矩阵，标记1表示路线冲突，0表示路线兼容。
- 程序自动为每条路线分配相位编号，并输出最终的相位划分方案。
- 严格遵循课程图片的分组操作步骤输出结果。

## 四、运行结果
经过代码运行计算，该五岔路口最少需要 4 个交通灯相位。
具体相位分配：
- 相位1：AB AC AD
- 相位2：BC BD
- 相位3：DA DB
- 相位4：EB EC

✅ 不受灯控右转线路（孤立顶点，任意相位均可通行）：BA DC ED
✅ EA线路：除相位1外，相位2、3、4均可通行

该方案保证了路口通行的安全性与高效性。
