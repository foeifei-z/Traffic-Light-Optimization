# 五岔路口交通灯相位优化设计 (Traffic-Light-Optimization)

## 一、 问题分析
本题是一个典型的五岔路口（包含单行道 C 和 E），总共有 13 条合法的可通行路线。
由于路口空间有限，部分路线存在交叉、合流或分流冲突，不能同时通行（如 E->B 和 A->D）；
而部分路线没有交叉，可以同时通行（如 A->B 和 E->C）。

## 二、 算法设计思路 (图论着色模型)
本设计将交通灯相位调度问题抽象为**图论中的“图着色问题”**：
1. **节点**：将 13 条可通行路线看作图的 13 个节点。
2. **边（冲突）**：如果两条路线在路口会发生冲突，则在它们之间连一条边。
3. **着色（相位）**：给节点分配颜色，同一种颜色代表同一个绿灯相位（可以同时通行）。
4. **目标**：使用最少的颜色数（最少相位）完成对所有节点的着色，保证相邻节点颜色不同。

## 三、 程序实现
使用 C 语言编写了贪心着色算法 (Greedy Coloring)：
- 建立了 13x13 的冲突矩阵 (adjacency matrix)，标记 1 表示冲突，0 表示兼容。
- 程序自动为每条路线分配颜色，并输出最终的相位划分方案。

## 四、 运行结果
经过代码运行计算，该五岔路口**最少需要 4 个交通灯相位**。
具体的相位划分方案由 C 语言程序自动计算并输出，保证了路口通行的安全性与高效性。
