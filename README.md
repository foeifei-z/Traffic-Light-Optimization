# 五岔路口交通灯相位优化设计 (Traffic-Light-Optimization)

## 一、 问题分析
本题是一个典型的五岔路口（包含单行道 C 和 E），总共有 13 条合法的可通行路线。由于路口空间有限，部分路线存在交叉、合流或分流冲突，不能同时通行（如 E->B 和 A->D）；而部分路线没有交叉，可以同时通行（如 A->B 和 E->C）。

## 二、 算法设计思路 (图论着色模型)
本设计将交通灯相位调度问题抽象为图论中的“图着色问题”：
1. **节点**：将 13 条可通行路线看作图的 13 个节点。
2. **边（冲突）**：如果两条路线在路口会发生冲突，则在它们之间连一条边。
3. **着色（相位）**：给节点分配颜色，同一种颜色代表同一个绿灯相位（可以同时通行）。
4. **目标**：使用最少的颜色数（最少相位）完成对所有节点的着色，保证相邻节点颜色不同。

## 三、 程序实现
使用 C 语言编写了贪心着色算法 (Greedy Coloring)：
* 建立了 13x13 的冲突矩阵 (adjacency matrix)，标记 1 表示冲突，0 表示兼容。
* **图预处理**：根据交通规则与图示逻辑，程序首先剥离了 3 个完全不受灯控限制的右转孤立点（BA, DC, ED）；随后识别出特殊节点 EA（它与颜色1组冲突，但与颜色2、3、4组均不冲突）。
* **贪心着色**：针对余下的 6 个复杂冲突节点（BC, BD, DA, DB, EB, EC），程序自动运行贪心着色算法，并输出最终的相位划分方案。

## 四、 运行结果
经过代码运行计算，该五岔路口最少需要 **4 个交通灯相位**。具体的相位划分方案由 C 语言程序自动计算并输出，保证了路口通行的安全性与高效性。

**详细相位分配如下：**
* **相位 1**：放行 AB、AC、AD。（注：此时 EA 不能通行）
* **相位 2**：放行 BC、BD，同时 EA 可通行。
* **相位 3**：放行 DA、DB，同时 EA 可通行。
* **相位 4**：放行 EB、EC，同时 EA 可通行。
* **完全不受灯控限制**：右转路线 BA、DC、ED 为孤立顶点，不受灯控限制，可在任意相位通行。
